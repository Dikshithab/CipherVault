# 🔐 CipherVault – Secure File Encryption & Decryption

A modern cybersecurity web application built with **Python Flask** that securely encrypts and decrypts files using the **Fernet symmetric encryption algorithm** from the Cryptography library.

---

# ✨ Features

- 🔑 Generate Encryption Key
- 🔒 Encrypt Files Securely
- 🔓 Decrypt Encrypted Files
- 📁 Drag & Drop File Upload
- 📥 Automatic File Download
- 🌙 Dark Mode
- 📱 Responsive Design
- 🔔 Toast Notifications
- ⏳ Loading Animation
- 🎨 Modern Glassmorphism UI

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Dikshithab/CipherVault.git
```

Move into the project

```bash
cd CipherVault```

Create virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```


# 🔐 How It Works

1. Generate a secure encryption key.
2. Upload a file.
3. The file is encrypted using the Fernet algorithm.
4. Download the encrypted file.
5. Upload the encrypted file to decrypt it.
6. Download the original file.
