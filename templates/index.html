How CipherVault Works

CipherVault protects your files using the Fernet Encryption Algorithm. Fernet is built on AES-128 symmetric encryption and provides both encryption and authentication. Instead of storing secret keys, the application generates a secure key directly from the password entered by the user.

🔑 Key Generation

The password is transformed into a 256-bit encryption key using PBKDF2-HMAC-SHA256. Over 100,000 iterations are performed, making brute-force attacks extremely difficult.

🛡 File Encryption

The generated key is used by the Fernet library to encrypt the uploaded file. A cryptographic authentication signature is also generated to verify file integrity.

📋 Encryption Workflow

  • 📂 Upload a file.
  • 🔑 Enter a secure password.
  • ⚙ PBKDF2 generates a secure key.
  • 🔐 Fernet encrypts the file.
  • 📥 Download the encrypted file (.enc).
  • 🔓 Upload the encrypted file for decryption.
  • ✅ Enter the same password to restore the original file.
Security Note: CipherVault never stores your password. The password exists only during encryption or decryption and is never saved anywhere.
